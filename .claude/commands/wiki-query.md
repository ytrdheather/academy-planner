`wiki/SCHEMA.md`의 **query** 절차로 다음 질문에 답하라.

**질문**: $ARGUMENTS

## 절차

1. **`wiki/index.md`를 먼저 읽는다.**
2. 관련 있어 보이는 페이지**만** 연다. 전부 열지 마라 — 이 위키의 존재 이유가 토큰 절약이다.
3. 답한다. 근거를 반드시 명시한다:
   - 위키 근거 → `wiki/patterns/notion-fetch.md`
   - 코드 근거 → `api/index.js:65`
4. 페이지에 `status: inferred`가 붙어 있으면 **그 사실을 답변에 밝혀라** — "코드로 확인되지 않은 내용"이라고.
5. **위키에 답이 없으면** 코드를 판다. 그 다음이 중요하다:
   > 찾아낸 것을 **곧바로 ingest 한다.** 같은 걸 두 번 파지 않기 위해서다.
   `/wiki-ingest` 절차대로 페이지를 만들거나 갱신하고 `log.md`에 남긴다.
6. 답 자체가 정리할 가치가 있으면(여러 페이지를 종합한 결론, 앞으로 또 물어볼 것) **새 페이지로 환원**한다.
7. 위키를 실제로 갱신했으면 `wiki/log.md`에 추가한다:
   ```
   ## [YYYY-MM-DD] query | 질문 요약 → 무엇을 새로 남겼는지
   ```
   (단순 조회로 끝났으면 log는 생략해도 된다.)

## 답변 형식

- 결론 먼저, 근거는 그다음.
- 코드를 고쳐야 하는 질문이면 **어느 파일 몇 줄인지**까지 짚어라.
- 위키가 부족해서 코드를 파야 했다면 그 사실도 알려라 — 위키의 구멍이 어디인지가 정보다.
