설치 주소

아래 주소로 들어가 로그인한 뒤, 홈 화면에 추가하면 끝입니다.

readitude.onrender.com

지금 열어서 로그인하기

아이폰 — 사파리로 설치

반드시 사파리로 열어야 합니다.

  1. 사파리에서 주소 열기
    주소창에 readitude.onrender.com 입력
  2. 먼저 로그인하기
    학원에서 받은 ID·비밀번호로 로그인하세요. 설치 전에 로그인해 두면 앱을 열자마자 바로 사용할 수 있어요.
  3. 오른쪽 아래 ⋯ 누르기
    화면 아래 오른쪽에 있는 점 세 개 버튼입니다.
  4. “공유” → “홈 화면에 추가” 누르기
    나오는 메뉴에서 공유를 누르면 홈 화면에 추가가 보입니다. 눌러서 오른쪽 위 추가까지 누르면 홈 화면에 리디플랜 아이콘이 생깁니다.
카카오톡으로 링크를 받았다면?
카톡 안에서는 “홈 화면에 추가”가 없습니다. 오른쪽 아래 메뉴에서 “사파리로 열기”를 먼저 눌러 주세요.

안드로이드 — 크롬으로 설치

삼성 인터넷에서도 되지만 크롬이 가장 확실합니다.

  1. 크롬에서 주소 열기
    주소창에 readitude.onrender.com 입력
  2. 먼저 로그인하기
    학원에서 받은 ID·비밀번호로 로그인하세요.
  3. 오른쪽 위 ⋮ 누르기
    주소창 오른쪽 끝의 점 세 개 버튼입니다.
  4. “앱 설치” 또는 “홈 화면에 추가” 누르기
    폰에 따라 둘 중 하나로 표시됩니다. 눌러서 설치를 확인하세요.
카카오톡으로 링크를 받았다면?
카톡 안에서는 설치 메뉴가 없습니다. 오른쪽 아래 메뉴에서 “다른 브라우저로 열기”를 눌러 크롬으로 열어 주세요.

카카오톡·네이버·인스타그램 앱 안에서 열린 화면이라 그렇습니다. 아이폰은 사파리, 안드로이드는 크롬으로 다시 열어 주세요.
로그인 정보를 모르겠어요
학원에서 안내받은 학생 ID·비밀번호입니다. 기억나지 않으면 담당 선생님께 문의해 주세요.
앱을 여니 로그인 화면이 다시 떠요
로그인은 30일 동안 유지됩니다. 30일이 지났거나 앱 데이터를 지웠으면 다시 로그인해 주세요.
숙제가 아직 안 보여요
그날 숙제가 아직 입력되지 않은 상태입니다. 숙제는 보통 오전 중에 올라옵니다. 오후에도 비어 있으면 담당 선생님께 문의해 주세요.
