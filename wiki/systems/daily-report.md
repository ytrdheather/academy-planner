## 한 줄

학생별 하루 학습 기록을 페이지로 만들고, Gemini가 학부모용 코멘트를 써서 알림톡으로 나간다.

## 흐름

```
10:20 크론  그날 수강요일 학생의 진도 페이지 생성 (멱등)
낮          선생님이 대시보드에서 진도·점수·키워드 입력
            → [AI 코멘트 생성] → 검토·수정 → 작성완료 체크
22:00 크론  진도 행에 데일리리포트URL 기록
밤          🔴 발송은 아직 Make → [[make-migration]]
```

**발송 로직은 우리 코드에 없다.** URL까지만 우리가 만들고, Make 시나리오가 그 URL을 읽어 알림톡을 보낸다. 템플릿 `NEW daily report 26.03.06` `KA01TP260306103448601CbxWHWGzEZN`.

## 🔴 리포트 화면은 '열 때 그린다'

`/report?pageId=…` 는 저장된 파일이 아니라 **열 때마다 노션을 읽어 그 자리에서 그린다.** 그래서 렌더가 깨지면 이미 나간 링크가 전부 에러가 되고, 고치면 **같은 링크가 재발송 없이 되살아난다.**

🔴 **2026-09-03: 모듈 분리 때 `parseDailyReportData` 주입을 빠뜨려 학부모 리포트가 이틀간 전멸했다.** 라우트의 `catch` 가 `ReferenceError` 를 `500 'Report Error'` 로 삼켜서 조용했다. 노션 데이터와 URL 은 멀쩡했다(그 둘을 만드는 크론은 이 함수를 안 쓴다) — 망가진 건 그리는 순간뿐이었다.

- **라우트가 '존재하는지'만 보는 테스트로는 못 잡는다.** 실제로 HTML 이 나오는지 봐야 한다 → [[test-harness]]
- 이 모듈을 다시 손댈 때는 주입 목록을 **`index.js` 최상위 정의 전부와 대조**하라. 손으로 쓴 후보 목록은 목록에 없는 이름을 검사하지 못한다.

## 계약 — AI 코멘트 프롬프트 (2026-07-12 확정·배포)

`POST /api/generate-daily-comment` (`api/index.js:1067`). **여러 차례 튜닝해 확정된 것이라 함부로 바꾸지 마라.**

- **말투: 담임 교사의 문어체.** 모든 문장 `~니다` 체. 🔴 **`~요`체 완전 금지**(~했어요/~예요/~네요/~더라고요). 느낌표 금지. `~한답니다` 등 유치원톤 금지 — 실제 나쁜 문장을 부정 예시로 프롬프트에 박아 뒀다. **온기는 어미가 아니라 내용(구체적 관찰·절제된 격려)으로.**
- **호칭은 코드가 만든다.** 성을 떼고 받침을 판별해 확정형태를 주입(재은→재은이는/재은이가, 시우→시우는/시우가). `hasBatchim = (code-0xAC00) % 28 !== 0`.
- 🔴 **사실 왜곡 금지.** "~까지 ~해오기"는 **앞으로 할 숙제**지 완료가 아니다. 없는 에피소드 지어내기 금지. 단 키워드에 명시된 긍정은 담담하게 꼭 전달.
- **숙제 미이행·낮은 수행율 → 쿠션어 없이 직설 + 실질 안내**(일찍 와서 하기/남아서 마치기). **점수 낮음·이해부족만** 쿠션어.
- **키워드 내용을 하나도 빠뜨리지 말 것. 코멘트가 키워드보다 짧아지면 안 된다**(압축 금지). few-shot 예시1을 "매끄럽게 이어지는 긴 문단"으로 바꾼 게 핵심 지렛대였다.
- **점수 브리핑은 코드가 만들어 주입한다.** 어휘/문법/독해/수행율 중 **실제 입력칸에 값이 있는 것만** — 수식은 빈칸도 `0%`/`PASS`를 내놓으므로 제외. 2문단 제목 `<📢 오늘의 학습 결과와 숙제 수행율 안내>`.
- **문법 코멘트는 AI를 거치지 않고 코드가 원문 그대로 삽입한다** → [[grammar-comment]]

**모델 설정**: `gemini-2.5-flash`, temperature 0.72, maxOutputTokens 2500, `thinkingBudget: 1024`. 비용은 하루 70원대. 256→1024로 올린 건 품질 때문. (참고: `api/index.js:104`의 전역 `geminiModel`은 temp 0.7 / 1500 / thinking 0 — 이 라우트는 자체 설정을 쓴다.)
