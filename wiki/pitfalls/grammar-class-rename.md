## 증상

2026-08-25. 문법 코멘트 작성 모달에서 **M1B** 반을 골라 저장하니 이렇게 떴다.

```
실패: select option "M1B" not found for property "반이름".
Available options: "P2", "P3", "5S", "5B", "56B", "M6A", "TM1B", "TM1A",
"M2", "M3", "HA", "NN", "F4", "AlB", "LS", "M12B", "2M6", "1M6".
```

드롭다운에는 **M1B가 멀쩡히 떠 있는데** 저장만 안 됐다.

## 원인

**반 이름을 M12B → M1B 로 바꿨는데, GRAMMAR_DB `반이름`(select) 옵션 목록에는 옛 이름만 남아 있었다.**

두 곳이 서로 다른 것을 보고 있었다.

| | 무엇을 보나 | 이름 변경에 |
|---|---|---|
| 드롭다운 · 학생 투사 | PROGRESS `문법클래스` **롤업** (학생 명부에서 따라옴) | 즉시 따라온다 |
| GRAMMAR_DB 원장 upsert | `반이름` **단일 선택(select)** | 손으로 안 채우면 영영 옛 이름 |

그리고 결정적인 것 — **노션은 등록되지 않은 옵션 이름으로 필터를 걸면 쿼리 자체를 거부한다.**
값을 못 찾는 게 아니라 400 이 난다. 그래서 "M1B 행이 없다"가 아니라 "요청이 틀렸다"가 됐다.

## 왜 하필 코멘트 저장에서만 보였나

같은 필터를 네 곳이 쓰고 있었는데 **에러를 삼키는 정도가 달랐다.**

| 경로 | 그때 상태 |
|---|---|
| 코멘트만 저장 | 감싼 게 없어 ①에서 멈춤 → **학생 투사까지 통째로 실패.** 눈에 보임 |
| 전체 저장 | 원장 쓰기만 `try/catch` → 로그만 남고 투사는 진행. **화면엔 성공.** 원장 행만 조용히 빔 |
| 오늘 기록 프리필 | 프론트가 `console.error` 로 삼킴 → **기존 코멘트가 있어도 빈칸** |
| 프로필 카드 최근 문법 | `allSettled` 로 묶임 → **그냥 빈 칸.** 아무도 몰랐다 |

🔴 **삼키는 정도가 다르면 같은 원인이 네 개의 다른 증상으로 보인다.** 하나가 터졌으면 같은 필터를 쓰는 나머지를 전부 세어 봐라.

## 고친 방법 (2026-08-25)

**찾는 것은 제목으로, `반이름` 은 계속 채우되 옵션을 자동으로 붙인다.**

- 원장 행은 제목(`이름`)이 `{반}-{날짜}` 라 그것만으로 유일하다. `grammarRowFilter()` 하나로 세 곳 통일 (`api/index.js:1620`). 제목 필터에는 옵션 검증이 없다.
- 프로필 카드는 날짜 없이 반만 보므로 `title starts_with "{반}-"`. **하이픈이 `M1B-` 가 `M12B-` 를 무는 것을 막는다.**
- `ensureGrammarClassOption()` (`api/index.js:1638`) — 쓰기 직전에 `반이름` 옵션에 그 반이 없으면 스키마에 붙인다. 5분 캐시, 기존 옵션은 통째로 되돌려 보낸다(이름만 추리면 색이 날아간다). 속성이 없으면 `false` 를 주고 호출부가 그 칸을 아예 안 쓴다.
- `findPageIdByTitle` 의 `반이름` select 분기 삭제 — 호출자 없는 죽은 코드였다 → [[notion-find-page]]

## 규칙

🔴 **select 속성으로 페이지를 찾지 마라.** 옵션 목록은 사람이 손으로 관리하는 목록이고, 이름은 바뀐다. 롤업·수식에서 따라오는 이름과 select 옵션은 **절대 자동으로 같아지지 않는다.**

🔴 **드롭다운의 출처와 저장의 출처가 다르면 언젠가 반드시 어긋난다.** 목록에는 뜨는데 저장은 안 되는 화면이 그 증거다.

## 남은 것

- 이름을 바꾸기 전에 쌓인 **`M12B-…` 행들**은 프로필 카드의 "최근 문법 진도"에서 안 잡힌다. 최근 3건만 보는 자리라 감수했다. 필요하면 노션에서 옛 행 제목을 일괄 수정하면 된다.
- 고친 뒤 **M1B 를 한 번 다시 저장**해야 그날 원장 행이 생긴다. 전체 저장이 조용히 실패하던 동안 학생 행에는 진도가 들어갔지만 원장에는 안 들어갔다.
