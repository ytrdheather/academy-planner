## [2026-08-15] ingest | 스킬 층 신설 — CLAUDE.md 를 안 키우기 위해

`CLAUDE.md` 는 **매 세션 자동 로드**라 여기 붙는 한 줄은 모든 세션이 값을 치른다. 그래서 절차를 이 파일이 아니라 스킬로 뺀다. **상한 200줄, 목표 50줄 이하**를 `CLAUDE.md` 안에 규칙으로 못 박았다 (현재 48줄).

### 세 층의 역할 분담 (이번에 확정)

| 어디에 | 무엇을 | 비용 |
|---|---|---|
| `CLAUDE.md` | 몰랐을 때 사고가 나는 것 + 한 줄 요약·포인터만 | 매 세션 |
| `.claude/commands/` | 여러 위키 페이지에 걸친 다단계 절차 | 그 작업 할 때만 |
| `wiki/` | 사실·계약·근거·이력. **기본값** | 열었을 때만 |

### 새 스킬 5종

| 스킬 | 왜 스킬인가 |
|---|---|
| `add-parent-message` | 되돌릴 수 없는 발송. 이미 반려된 알림 목록 확인 → 템플릿 심사 → env → 변수명 대조 → 1건 실발송 → `/messages` 되읽기. 위키 4페이지에 걸친다 |
| `add-cron` | timezone 누락 · 콜백 안 `new Date()` · 수동 트리거 라우트 · **배포 회피 시간대 등록**까지 빠뜨리기 쉽다 |
| `add-module` | `index.js`(3,782줄)를 더 키우지 않게. 주입 목록·`try/catch`·위키 갱신 대상이 흩어져 있다 |
| `deploy-check` | 자동 배포 꺼짐 + 배포가 크론을 죽인다. 시각 판단이 필요하다 |
| `diagnose-not-sent` | 사고가 두 번 났던 영역. 채널별 원인이 다르고 **시간순 정렬**을 안 하면 오진한다 |

**원칙: 스킬은 위키를 복제하지 않고 조율한다.** 내용은 위키에 두고 스킬은 순서와 포인터만 갖는다 — 두 곳에 같은 사실을 쓰면 갈라진다.

### 점검

- `CLAUDE.md` 48줄 / 3,051자 (상한 200줄의 24%)
- 스킬 8개 평균 47줄
- 스킬이 가리키는 위키 경로 **19건 전수 확인, 전부 존재**
- frontmatter YAML 파싱 8건 전부 정상 — `diagnose-not-sent`의 `description`이 따옴표로 시작해 깨졌던 것을 고쳤다

## [2026-08-17] ingest | 학사일정 기간 일정 + 달력 모듈 분리

**요청**: 학부모 공지에서 전·후 달 학사일정을 보고, 다음 달을 미리 만들어 저장하고, "18일부터 20일까지 학원방학"처럼 기간 이벤트를 지정하고 싶다.

**먼저 확인한 것 — 절반은 이미 있었다.** `/notice`의 ◀▶ 월 이동, `/calendar`의 ◀▶ 로 미래 달 미리 작성, 과거 기록 보존(노션), 학부모 화면의 `~` 기간 표시 코드(`fmtRange`)까지 전부 있었다. 실제로 막혀 있던 것은 두 개뿐이었다.

| 막혀 있던 것 | 왜 문제였나 |
|---|---|
| 기간 입력 수단이 없음 | POST가 `start`만 썼다. 18~20일 방학이 점 3개·줄 3개로 나갔다 |
| 이벤트 이름 입력칸이 없음 | 제목이 `"이벤트"`로 저장되고, 학부모 목록은 `내용` 있는 것만 띄워서 **보라색 점만 보였다**. 무슨 행사인지 알 수 없었다 |

**한 것**

- `api/calendarModule.js` 신설 ([[module-di]] 규칙, `try/catch` 포함). `index.js`에서 147줄 제거.
- 기간 일정: 달력에서 시작일·종료일을 차례로 누르면 묶인다. 주 단위로 끊어 **알약 모양**으로 그리고 이름을 그 아래 적는다 → PNG로 내보내도 읽힌다.
- 🔴 **기간의 주인은 시작일이 있는 달.** 달 넘는 기간(12/28~1/3)이 반대쪽 달을 저장할 때 사라지지 않게 하는 핵심 규칙. 넘어온 달에서는 읽기 전용으로 보여주고(안 보여주면 두 번 찍는다) **시수 계산에는 넣는다.**
- 중복 판정 키 `날짜|유형` → `시작일|종료일|유형|제목`. 같은 날 다른 이름의 행사 두 개가 가능해졌다.
- 학부모 화면: 걸치는 날 전부 칠하고, 이름만 지어도 목록에 뜨고, 목록을 "걸치는 달" 기준으로 모은다. 범례에 **학원 행사**(보라) 추가 — 양쪽 달력 모두 빠져 있었다.
- 보강일은 손대지 않았다. 결석 폼 선택지라 하루 단위·시간 메모 유지.

**검증**: 9~10월에 실제 저장/조회/삭제까지 돌리고 원복. 8월 기존 4건 무손상. 달 넘는 기간을 10월에서 빈 상태로 저장해도 9월 것이 남는 것 확인. 넘어온 휴강이 10월 시수에서 빠지는 것 수치로 확인(월수금 13→12, 화목 9→8).

**갱신한 페이지**: [[absence-notice]] (기간 규칙·학부모 월 이동 절 추가, source 갱신)
