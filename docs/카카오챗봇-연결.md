# 카카오톡 채널 챗봇 연결하기

학부모가 채널에 친 말을 알아듣고 **해당 폼으로 안내**하는 봇이다.
지금까지 원장이 직접 답하던 자리라, 봇이 어설프게 끼어들면 지금보다 나빠진다.
그래서 **봇은 안내판 역할만 한다.** 답을 지어내지 않고, 못 알아들으면 사람에게 넘긴다.

## 봇이 하는 일

```
학부모: "연우 조금 늦을것같습니다"
   → 봇: "지각은 아래에서 알려주시면 담당 선생님께 바로 전달됩니다"
         [지각 알려주기] 버튼 → /absence

학부모: "오늘 날씨가 좋네요"
   → 봇: "선생님께 전달했습니다. 수업이 끝난 뒤 확인하고 답장드립니다"
   → 동시에 원장 카카오워크로 그 문장이 그대로 전달됨
```

**봇은 학부모가 누구인지 모른다.** 오픈빌더가 주는 건 익명 키뿐이라 학생 이름이 없다.
그래서 봇이 직접 노션에 기록하지 않는다 — 누구 건지 모르는 기록은 쓸모가 없다.
폼으로 보내야 거기서 이름을 받아 담임·연락처가 잡힌다. **그게 이 봇의 존재 이유다.**

## 원장이 챗봇 관리자센터에서 할 일

### 1. 스킬 등록

왼쪽 메뉴 **`스킬`** → 스킬 만들기

| 칸 | 넣을 값 |
|---|---|
| 스킬명 | `리디튜드 안내` |
| URL | `https://readitude.onrender.com/api/kakao/skill` |

저장하면 끝이다. 다른 칸은 건드리지 않는다.

> 나중에 아무나 못 부르게 막고 싶으면 Render 에 `KAKAO_SKILL_SECRET` 을 넣고,
> 스킬 설정의 헤더에 `x-skill-secret` 으로 같은 값을 넣으면 된다. 지금은 없어도 동작한다.

### 2. 폴백 블록에 스킬 연결

왼쪽 **`시나리오`** → **`폴백 블록`**

폴백 블록은 **"봇이 못 알아들었을 때 가는 곳"** 이다. 여기에 스킬을 걸면
**모든 말이 우리 서버로 넘어온다.** 분류는 서버가 한다.

1. 폴백 블록을 연다
2. 응답 부분에서 **스킬 선택** → 방금 만든 `리디튜드 안내`
3. 저장

### 3. 배포

왼쪽 **`배포`** → 배포하기.
**배포를 눌러야 실제로 반영된다.** 저장만 하면 안 바뀐다.

### 4. 채널 연결

지금 봇 상태가 `운영채널: 연결된 채널 없음` 이다.
**`설정`** 에서 리디튜드 카카오톡 채널을 연결한다.

### 5. 확인

카카오톡에서 리디튜드 채널에 직접 쳐 본다.

```
"연우 늦어요"        → 지각 안내 + 버튼
"오늘 날씨 좋네요"    → "선생님께 전달했습니다" + 원장 카카오워크에 알림
```

## 봇이 알아듣는 말

실제로 받은 학부모 문장으로 시험한 결과다(2026-08-08).

| 문장 | 결과 |
|---|---|
| 연우 조금 늦을것같습니다 | ✅ 지각 |
| 양호준 … 15시에 귀가해야할 것 같습니다 | ✅ 조퇴 |
| 서연이는 … 하루 쉬겠습니다 | ✅ 결석 |
| 건영이가 이번주 금요일 결석을 … | ✅ 결석 |
| 아인이 교재비 입금을 아빠이름으로 … | ✅ 교재비 |
| 8월 일정은 언제쯤 공지주시나요 | ✅ 일정 |
| 준수가 냉방병인지 … 시간이 부족해서 … 등원예정입니다 | ❌ 미분류 |
| 준서,서형이가 … 지도해 주실 수 있을까요 | ❌ 미분류 |

**놓친 둘은 그냥 두는 게 맞다.** 완곡하게 돌려 쓴 문장이라 규칙으로 잡으려다 보면
엉뚱한 것까지 잡는다. **오탐이 미탐보다 나쁘다** — 잘못 분류하면 학부모가 엉뚱한 폼으로 가고,
못 알아들으면 사람에게 넘어가서 지금과 같아진다.

말을 더 잡고 싶으면 `api/kakaoSkill.js` 의 `RULES` 에 단어를 넣으면 된다.

## 더 똑똑하게 하려면 (나중)

지금은 **폴백 블록 하나 + 우리 서버의 단어 맞추기**다. 단순해서 오늘 바로 된다.

오픈빌더 본래 방식은 **유형별 블록을 만들고 각 블록에 예시 발화를 등록**하는 것이다.
그러면 카카오가 자연어로 매칭해 줘서 "등원예정입니다" 같은 완곡한 표현도 잡는다.
대신 원장이 콘솔에서 블록 5개를 만들고 문장을 여러 개씩 적어야 한다.

**먼저 지금 방식으로 며칠 써 보고**, 놓치는 게 많으면 그때 블록으로 올리는 순서를 권한다.

## 🔴 "봇이 안 뜬다" 고 할 때 — 대부분 이것이다

카카오톡 채팅방 아래에 **`상담 연결`** 버튼이 있고, 학부모가 그걸 누르면 **사람과 대화하는 모드**가 된다.
그 상태에서는 **봇이 아무 답도 하지 않는다.** 설정이 잘못된 게 아니다.

```
챗봇 채팅중   ← 이때만 봇이 답한다 (입력창에 "챗봇에게 메시지 입력")
상담 연결됨   ← 봇은 빠지고 사람이 답해야 한다
```

2026-08-10 에 이것 때문에 한참 헤맸다. 스킬·폴백·배포·채널 연결이 전부 정상인데
채널에서만 답이 없었고, 원인은 상담 모드였다. **다음 순서로 확인하면 빠르다:**

1. 챗봇 관리자센터의 **봇 테스트 창**에서 쳐 본다 → 여기서 되면 봇 자체는 정상
2. 카카오톡 채팅방 상단이 **`챗봇 채팅중`** 인지 본다 → 아니면 상담 모드다
3. 그래도 안 되면 배포 시각이 마지막 수정보다 뒤인지 본다

> **채팅(상담) 기능을 끄지 말 것.** 끄면 `상담 연결` 버튼이 사라져 급한 일에 사람을 못 찾는다.
> 이 버튼이 봇의 탈출구 역할을 한다.

## 학부모가 봇을 쓰게 하려면

기본이 상담 모드면 봇이 무용지물이 된다. 두 가지로 유도한다.

- **첫인사 메시지**(채널 관리자센터 → 채팅 설정)에 "결석·지각·조퇴는 챗봇에게 말씀해 주시면
  바로 안내해 드립니다. 선생님과 직접 이야기하시려면 상담 연결을 눌러주세요" 를 넣는다
- **채널 커스텀 메뉴**에 폼 주소를 직접 건다. 채팅을 안 거치고 바로 간다

```
출결·보강  →  https://readitude.onrender.com/absence
상담 신청  →  https://readitude.onrender.com/counsel
공지사항   →  https://readitude.onrender.com/notice
```

메뉴와 챗봇은 겹쳐도 손해가 없다. 메뉴는 누르는 사람용, 챗봇은 그래도 톡을 치는 사람용이다.

  기계와 씨름하게 되면 지금보다 나빠진다. 그래서 미분류는 반드시 사람에게 넘긴다
- 답변에 학원 전화번호(031-273-6737)를 넣어 뒀다. 급하면 전화하시라는 탈출구다
- 시험은 **원장 본인 카카오톡으로** 하면 된다. 학부모에게 가는 것이 아니다
