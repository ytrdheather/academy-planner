## 1. 시작 전 상황 (이미 있던 것)

학생용 인프라는 대부분 이미 있었음. 새로 만든 건 3가지뿐.

| 기능 | 상태 | 위치 |
|---|---|---|
| 학생 로그인 (노션 학생 DB의 `학생 ID`/`비밀번호`) | 이미 있음 | `POST /login`, `views/login.html` |
| 숙제 제출 폼 (6개 항목 + 사진 인증샷) | 이미 있음 | `views/planner-modular.html`, `POST /save-progress` |
| 스터디 플래너 입력 / 스터디 로그 / 시험 답안 입력 | 이미 있음 | 같은 파일 |
| **폰에 앱으로 설치** | ❌ → 새로 만듦 | PWA |
| **오늘 숙제가 뭔지 보는 화면** | ❌ → 새로 만듦 | 데이터는 노션에 이미 있었으나 학부모 리포트에만 노출됨 |
| **학생용 데일리 리포트** | ❌ → 새로 만듦 | `/report`는 학부모용 |

## 2. 만든 것

### (1) PWA — 폰 홈 화면에 앱으로 설치

앱스토어·플레이스토어 등록 **불필요**. 사파리/크롬에서 "홈 화면에 추가"하면 아이콘 생기고 주소창 없이 전체화면으로 뜸.

- `public/manifest.json` — 앱 이름 "리디플랜", `start_url: /planner`, `display: standalone`
- `public/sw.js` — 서비스워커. **`/assets` 정적 파일만 캐시하고 학생 데이터(페이지·API)는 절대 캐시 안 함.**
  (지난 학생 데이터가 캐시돼서 잘못 보이는 것보다 안 보이는 게 낫다는 판단)
  코드 고치면 `CACHE_VERSION` 숫자만 올리면 학생 폰의 옛 캐시가 자동 삭제됨.
- `public/assets/icon-192.png`, `icon-512.png`, `apple-touch-icon.png` — `logo.png`에서 정사각형으로 생성
- 서버 라우트: `GET /manifest.json`, `GET /sw.js` (서비스워커는 **반드시 루트에서** 내려줘야 사이트 전체가 scope)
- `login.html` / `planner-modular.html` / `my-report.html` head에 PWA 메타태그 + 서비스워커 등록 스크립트

### (2) 📚 오늘의 숙제 — `GET /api/my-homework`

학생 메뉴 **맨 위** 버튼. 읽기 전용.

- **핵심 로직:** 오늘 수업 행이 아직 없을 수 있으므로, 최근 행 10개를 날짜 내림차순으로 훑어서
  **숙제 내용이 실제로 채워진 가장 마지막 수업**을 찾아 반환. 그래서 집에서 열어도 지난 수업 숙제가 보임.
- 노션 속성: `오늘 문법 진도`, `문법 숙제 내용`, `어휘숙제`, `주독해숙제`, `부독해숙제`
- 자동생성 숙제(어휘/주독해/부독해)는 학부모 리포트와 **같은 스위치**(`SHOW_GENERATED_HOMEWORK`)를 따름
- 화면 하단 "숙제 다 했어요 → 제출하러 가기" 버튼으로 기존 숙제 제출 폼과 연결

### (3) 📊 나의 데일리 리포트 — `/my-report`

- **`/report`(학부모용)를 재사용하지 않음.** `/report`는 `pageId`만 알면 **인증 없이 누구나 열리는** 공개 링크라서,
  학생용으로 쓰면 남의 리포트도 열림. 그래서 토큰 기반으로 따로 만듦.
- `GET /my-report` → `public/views/my-report.html` (껍데기 페이지, 인증 불필요 — 데이터가 없으므로)
- `GET /api/my-report-dates` → 본인 리포트 있는 날짜 최근 30개. 드롭다운 채우고 **가장 최근 것부터** 자동 표시
- `GET /api/my-report?date=` → 본인 리포트 HTML. 날짜 지정했는데 그 날 행이 없으면 404 (엉뚱한 날짜 리포트 방지)
- **템플릿은 학부모용과 공유.** `buildReportHtml(parsed, forStudent)` 함수로 뽑아냈고,
  `forStudent=true`면 `dailyreport.html`의 `<!-- STUDENT_HIDE_START -->` ~ `<!-- STUDENT_HIDE_END -->` 구간을 정규식으로 통째 제거.
  → **앞으로 학생에게 감출 섹션이 생기면 그 마커 사이에 넣기만 하면 됨.**
- 렌더링은 iframe `srcdoc`으로. 툴바(날짜 선택 + 플래너로 가기)는 유지되고 리포트 스타일은 격리됨

### (4) 선생님 코멘트 차단

**학생이 이미 코멘트를 보고 있었음** — "나의 스터디 로그 보기"에서 `❤ Today's Notice!`를 그대로 띄우고 있었다. 두 군데를 막음:

- `planner-modular.html`: 스터디 로그의 선생님 코멘트 블록을 주석 처리 (되살리려면 주석 해제 + 아래 delete 두 줄 제거)
- `api/index.js` `/api/get-today-progress`: **응답에서 서버가 `❤ Today's Notice!` / `Today's Notice!`를 삭제.**
  화면에서 안 그리는 것만으로는 개발자도구 네트워크 탭에 그대로 보이기 때문.

### (5) 학생 토큰 30일

`generateToken()`이 role을 보고 분기 — 학생 `30d`, 선생님 `24h`(공용 PC 대비 짧게 유지).
로그인 화면은 토큰이 있으면 바로 `/planner`로 넘어가 앱처럼 열림.

## 4. ⚠️ 배포 전 미결정 사항 — `SHOW_GENERATED_HOMEWORK`

**현재 꺼져 있음.** 이 상태로 배포하면 학생 "오늘의 숙제" 화면에 **문법 숙제만** 뜨고
어휘/주독해/부독해는 안 보인다 (학부모 리포트와 같은 스위치를 따르게 했기 때문).

- 전체를 보여주려면: **Render 환경변수에 `SHOW_GENERATED_HOMEWORK=true` 추가 후 재시작.** 코드 배포 불필요.
- 단, 이 스위치는 `api/index.js` 주석대로 **학생별 교재 업데이트 검증이 끝날 때까지 꺼두기로 했던 것**.
  그 검증이 끝났는지에 따라 결정할 것.
- 문법 숙제는 이 스위치와 무관하게 항상 노출됨.

## 5. 검증한 것 (2026-07-28, 로컬)

로컬 서버(`node api/index.js`, 포트 5001)를 띄우고 확인:

- 새 라우트 전부 200: `/manifest.json`, `/sw.js`, 아이콘 3종, `/my-report`, `/planner`
- **권한 격리**: 학생 API 3개 모두 무토큰 → 401, **선생님 토큰 → 403** (남의 리포트 조회 불가)
- 서비스워커 루트 scope(`http://localhost:5001/`) 등록·활성화, 매니페스트 정상 파싱, 콘솔 에러 없음
- 리포트 잘라내기: 코멘트만 제거되고 `<section>` 5:5 균형 유지, 다른 `{{PLACEHOLDER}}` 전부 온전
- 숙제 목록에 `<script>` 태그 주입 테스트 → 글자로 출력됨 (XSS 안전)
- 스터디 로그: 코멘트 DOM 제거 후에도 JS 에러 없이 정상 동작

**검증 중 발견해 고친 버그 2개**
1. 서버 오류(500)일 때 "숙제 없음" / "리포트 없음"으로 잘못 안내되던 것 → `res.ok` 체크 분리
2. 만료된 토큰일 때 로그인 ↔ 플래너 **무한 리다이렉트** → 401 시 `localStorage.removeItem('authToken')` 추가

## 5-1. 리디플랜 브랜딩과의 병합 (커밋 `a5eeb50`)

학생앱 작업 중 원격에 **리디플랜 브랜딩 + 민트 테마 리스킨** 12개 커밋이 올라와 있어 병합함.
원격 디자인을 기준으로 삼고 학생앱 추가분을 거기에 맞춤:

- 폰트: NanumSquareRound → **Pretendard** (login.html, my-report.html)
- 색: 보라(#7c3aed / #6b46c1) → **민트/틸** (#0d9488 강조, #0a6c62 제목, #17242e 본문)
  → `theme-color`, `manifest.json`, 오늘의 숙제 화면 스타일 전부 반영
- **라우트 충돌은 없었음**: 원격은 `/api/auto-generate-homework`, `/api/advance-homework` 추가,
  학생용은 `/api/my-homework`, `/my-report` 계열이라 이름이 겹치지 않음
- 숙제 속성명(`어휘숙제`/`주독해숙제`/`부독해숙제`)과 `SHOW_GENERATED_HOMEWORK` 스위치는 양쪽 모두 그대로 유지됨

병합 후 재검증: 서버 기동 OK, 주요 페이지 전부 200, 권한 격리(무토큰 401 / 선생님 403) 유지,
플래너 메뉴 6개(기존 4 + 신규 2) 정상, 충돌 마커 잔여 없음.

## 6. 알아둘 함정

- **`node_modules`가 git으로 추적되고 있음** (`.gitignore`가 Python 템플릿이라 `node_modules/`가 없음).
  로컬 `node_modules`에 `is-mergeable-object`(deepmerge의 의존성)가 빠져 있어 서버가 안 떴고,
  `npm install`은 "up to date"라고만 해서 `npm install --no-save is-mergeable-object@1.1.1`로 해결.
  Render는 새로 설치하므로 배포엔 문제없음.
- 로컬엔 `.env`가 없어서 노션 호출은 전부 실패함. 라우팅·권한·렌더링만 로컬 검증 가능.
- 선생님 토큰은 `teacher_auth_token`, 학생 토큰은 `authToken`으로 키가 달라서 로그인 화면 자동 리다이렉트가 선생님에게는 영향 없음.
